# REFERENCE — Lifecycle email strategy (retention + churn reduction)
# Source: Writesonic lifecycle flow (Chaitanya's design)

## Pre-trial popups
- Product page (SEO/Chatsonic/Article Writer) → Free Trial popup
- Pricing page → Contact Sales popup (lead → SDRs)
- Certain pages → Demo popup

## Payment abandoned flow (3 emails)
1. After 30 min of payment failure: "noticed you were interested" + plans + CTA buy
2. Day 2: hesitation framing + customer case study with numbers + contact sales
3. Day 2: tangible value reminder + CTA buy now

## Trial activation flow (welcome day 1-2 same for all)
Email 1/Day 1: Welcome + intro Writesonic + benefits + CTA first generation
Email 2/Day 2: How Writesonic solves problem + other features + ease + CTA first generation

### Branch: Made first generation?

**NO path (dormant risk → win-back → deactivate)**
- Day 3: "didn't get a chance" + demo video + CTA
- Day 4: "easier than it seems" + case study + CTA try
- Day 5: "we know you are busy" + book a demo
- Day 8: account expires in 7 days + customer success + offer extension
- Day 11: thank-you + feedback ask ("what was missing?")
- Then: deactivate

**YES path (activation → upgrade)**
- Day 3: future pace + ROI overview + book demo
- Day 4: similar features + tutorial video + we are here
- Day 6: upgrade to paid + customer success + benefits
- Email 5: pricing plans + benefits + CTA upgrade
- Email 6: benefits bullets + competitor comparison + 20% off annual
- Email 7-8: feedback + testimonial + more free credits

**Out-of-credits sub-flow**
- Different pricing plans + benefits paid + CTA upgrade
- How they liked it + more credits + contact sales

## Post-upgrade flow (by plan: Chatsonic / Individual / Teams / Enterprise)
6 emails per plan, same structure:
1. Welcome to plan + features they have access to
2. How to be successful with plan + USPs mapped to use cases + small video
3. Social proof (customer wins, testimonials, what they did + results)
4. APIs / integrations callout
5. Compare features with ChatGPT/Perplexity/Copy.ai/Surfer/Jasper + feedback CTA
6. Upsell to next tier (add team member, enterprise plans, custom)

## Retention loops

### Out of credits (paid users)
1. Overview current results + add-on packages + CTA add credits
2. Show how upgrading is more cost effective
3. Remind running out + social proof of upgrading

### Achievement / Milestone flow
- Individual/Teams branch: First article from AW + AI editor showcase + WordPress integration
- Then milestone 2 + roadmap + industry tips + SEO checker
- Then value messaging + additional insights + tips and tricks
- Chatsonic branch: Did 50 generations milestone

### Churn prevention (paying customer, 14 days no login)
1. Previous stats + go back and use it
2. FOMO + unique benefits
3. Testimonial + how others are using it
4. Contact us if facing issues

### Referral flow (paid 60+ days)
1. Upload testimonial/video → X free credits per 1k views
2. Reminder + showcase people who did it + benefits reaped

## Key principles encoded
- Branch on activation behavior (made first generation Y/N)
- Branch by plan tier for relevant onboarding
- Always include social proof in upgrade asks
- FOMO + tangible value in win-back sequences
- Feedback loops at email 5-7 (not too early)
- Referrals only after 60 days of paying = high trust signal
- Deactivate dormant accounts (don't keep emailing forever)
